# How to Use This Repository

Clone the repository:

```bash
git clone https://github.com/<your-username>/vcreatek-training.git
```

Navigate into the repository:

```bash
cd vcreatek-training
```

Open the required lab folder:

```bash
cd week1-foundations
```

or

```bash
cd week1-python-fluency
```

Run the Python program:

```bash
python3 main.py
```
